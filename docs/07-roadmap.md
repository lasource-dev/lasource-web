# Roadmap

La roadmap exprime un ordre d'apprentissage, pas des dates garanties.

## Phase 0 — Fondation

- stabiliser Next.js, Payload CMS, PostgreSQL et TypeScript strict ;
- établir les documents de référence, l'ADR initial et les contrôles automatisés ;
- clarifier taxonomie, workflow et règles de confiance.

## Phase 1 — Première entité métier

- créer la collection Technologie et son cycle brouillon/publication ;
- proposer une page publique fiable, accessible et indexable ;
- ajouter des données de démonstration et des tests ;
- valider le modèle avec un petit nombre de technologies IA.

## Phase 2 — Profondeur documentaire

- relier présentations, cas d'usage, installations, concepts, erreurs, tutoriels, recettes et FAQ ;
- structurer sources, versions, compatibilités et alternatives ;
- outiller la vérification et la fraîcheur.

## Phase 3 — Distribution

- ouvrir progressivement newsletter, MCP, API et Skills ;
- définir un contrat par canal sans dupliquer la connaissance ;
- observer les usages avant d'ajouter de nouveaux formats.

## Phase 4 — Échelle maîtrisée

- étendre les écosystèmes et catégories selon la demande ;
- industrialiser la mise à jour assistée sans retirer la validation humaine ;
- renforcer performance, gouvernance et mesure de la confiance.

Chaque phase peut être réordonnée si les retours utilisateurs ou les contraintes de maintenance l'exigent.
