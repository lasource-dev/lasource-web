# HTML

HTML décrit la structure et le sens d’une page web. Il indique qu’un contenu est un titre, un paragraphe, une navigation, une image ou un formulaire.

```html
<!doctype html>
<html lang="fr">
  <head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title>Découvrir HTML</title>
  </head>
  <body><main><h1>Découvrir HTML</h1></main></body>
</html>
```

Choisissez un élément pour son rôle, pas pour son rendu. Utilisez un véritable `<button>` pour une action et un `<a>` pour naviguer. Les éléments natifs apportent des comportements clavier et des informations aux technologies d’assistance.

## À apprendre

- structure d’un document ;
- titres, paragraphes, listes et liens ;
- images et alternatives textuelles ;
- formulaires et labels ;
- sémantique et accessibilité.
