# Vision

LaSource.dev est une plateforme documentaire vivante sur les technologies de développement, d'abord centrée sur l'écosystème IA.

## Problème

La connaissance technique est dispersée entre documentations officielles, dépôts, annonces, tutoriels et retours d'expérience. Elle vieillit vite, manque souvent de provenance et se répète différemment selon les canaux.

## Ambition

LaSource.dev transforme ces signaux en connaissance structurée, sourcée, datée et relue. Une Technologie constitue le point d'entrée stable ; les contenus qui l'expliquent ou la comparent évoluent autour d'elle.

La même connaissance peut ensuite alimenter :

- le site web pour la découverte et l'apprentissage ;
- la newsletter pour la veille ;
- le serveur MCP, l'API et les Skills pour les usages programmatiques ;
- les formations pour la transmission structurée ;
- d'autres formats sans duplication du fond.

## Horizon

Le projet commence petit : un modèle clair, quelques technologies bien documentées et un workflow éditorial fiable. L'élargissement des sujets et des canaux dépendra de la qualité obtenue, de la fraîcheur maintenue et des usages observés.

La vision produit complète est définie dans [`PRODUCT.md`](../PRODUCT.md).
