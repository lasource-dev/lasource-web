# Développement front-end

Le développement front-end concerne ce que le navigateur affiche et ce avec quoi une personne interagit : textes, formulaires, menus et retours d’erreur. Une bonne interface doit être compréhensible, accessible, rapide et robuste.

## Les fondations

HTML donne du sens au contenu. CSS contrôle la présentation et l’adaptation aux écrans. JavaScript ajoute le comportement. Ces trois technologies suffisent déjà à construire de nombreuses interfaces ; React devient utile lorsque les composants et les états se multiplient.

## Parcours conseillé

1. Créer une page sémantique en HTML.
2. La rendre responsive avec CSS.
3. Ajouter une interaction en JavaScript.
4. Manipuler des données provenant d’une API.
5. Découvrir les composants et l’état avec React.

La qualité d’une interface ne se mesure pas seulement à son apparence, mais à la facilité avec laquelle chacun peut atteindre son objectif.
